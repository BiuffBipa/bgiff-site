# چیزهایی که فقط از امیر لازم است

کوتاه، فقط موارد ضروری. هر مورد یک خط. چیزی که اینجا نیست، خودم تصمیم گرفته‌ام و در `DECISIONS_BUILD.md` نوشته‌ام.

## ۱. یک تصمیم (همین حالا)

- **Supabase**: پروژهٔ جدا و اختصاصی `bgiff-platform` با پلن Pro (۲۵ دلار/ماه) — پیشنهاد من — یا ماندن در پروژهٔ مشترک `amir-digital-holding`؟
  فقط بنویس «جدا» یا «مشترک». (پروژهٔ BIUFF در هر دو حالت دست نمی‌خورد.)

## ۲. کلیدها (خودت وارد کن، در چت نفرست)

همه در Vercel → Project `bgiff-site` → Settings → Environment Variables (نام دقیق متغیرها در `.env.example`):

1. Supabase: URL، `anon key`، `service_role key`، `DATABASE_URL` (بعد از تصمیم بند ۱)
2. FilmFreeway: API key (فقط خواندن) + Webhook secret
3. FestHome: Webhook secret (Edit Festival → API)
4. Resend: API key + رکوردهای DNS برای `mail.bgiff.com` و `news.bgiff.com`
5. Stripe: کلیدهای **تست** (Live فقط بعد از «برو» تو)
6. Bunny.net: ساخت Storage Zone (EU) + Stream Library، سپس کلیدها
7. Anthropic API key
8. Sentry DSN (اختیاری تا فاز F)
9. یک رشتهٔ تصادفی برای `HASH_PEPPER` و `CRON_SECRET` (می‌توانم بسازم؛ فقط باید خودت در Vercel بگذاری)

## ۳. مدارک

- دو فایل CSV تست (۲۷ سپتامبر، FilmFreeway + FestHome) → در پوشهٔ `12_Archive/data/` یا ضمیمهٔ چت بعدی
- USt-IdNr (شمارهٔ مالیات بر ارزش افزوده) برای Impressum و فاکتور
- متن نهایی سه رضایت: مجوز نمایش آنلاین (L-03)، قوانین Gates (خصوصی، فقط داخل داشبورد)، خبرنامه — یا بگو از سندهای موجود پیش‌نویس کنم
